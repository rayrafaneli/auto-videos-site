Política de Privacidade

Atualizada em 28 de setembro de 2026

O que é

O auto-videos é uma ferramenta pessoal que publica vídeos curtos nos canais do YouTube do próprio autor (Refúgio da Alma, QI Supremo e Fato Oculto). Ela usa os Serviços de API do YouTube. Ao usar esta ferramenta, você concorda com os Termos de Serviço do YouTube, e os dados tratados pela API também seguem a Política de Privacidade do Google.

Quais dados acessamos

  • O nome e o ID do canal autorizado (para confirmar que os vídeos vão para o canal certo).
  • Os vídeos enviados pela própria ferramenta e o status deles (privado, agendado, público), para agendar, publicar ou apagar esses vídeos.

Não acessamos, coletamos nem armazenamos dados de espectadores, comentários, inscritos, mensagens ou qualquer informação de outros usuários.

Como usamos e guardamos

Os dados são usados somente para publicar e gerenciar os vídeos dos canais do autor. O token de autorização fica guardado de forma privada (arquivo local e segredos criptografados do GitHub Actions) e nunca é exibido, vendido ou compartilhado com terceiros. Não usamos cookies nem rastreamento.

Compartilhamento

Nenhum dado é compartilhado com terceiros. Os vídeos são enviados apenas ao YouTube.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta do Google: myaccount.google.com/permissions. Depois de revogado, a ferramenta não consegue mais publicar e os dados de autorização guardados são apagados em até 7 dias, ou imediatamente mediante pedido pelo contato abaixo.
